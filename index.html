About

Portfolio Analyzer Pro

A comprehensive portfolio analysis tool with live market data, backtesting, and risk analytics.

Data Sources: Finnhub API (live) / Built-in sample data (demo)

Metrics: Beta, P/E, Forward P/E, Delta, Gamma, Alpha (Jensen's), Market Cap, Volume, Yield, Sharpe, Sortino, Max Drawdown, CAGR

Delta = regression sensitivity to SPY. Gamma = rate of change of delta. Alpha = Jensen's alpha via CAPM. All computed from historical returns.
