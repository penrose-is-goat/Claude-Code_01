Local market research tools

Portfolio Analyzer Side Tools

Auditable macro, Fed probability, and Treasury auction research tools. Each result shows its provider, native identifier, date coverage, and fallback status.

Macro Data Lab Chart market, macro, index-earnings, company-fundamental, and cross-country data. Routes across S&P, SEC, World Bank, Treasury, BLS, market providers, and FRED. Fed Tracker Load EFFR, target range, Fed funds futures, and implied meeting distributions. CME settlements primary; indicative market closes are labeled separately. Treasury Auction Tracker Explore every official auction, result, bidder mix, and source document. Live upcoming auctions, historical charts, result PDFs, and a local searchable database.

Run it in VS Code

Open this folder in VS Code, choose Run and Debug, then run Run Portfolio Analyzer Side Tools. The preflight stops before opening a backend that cannot reach the data sources.

python serve.py --doctor
python serve.py --check
