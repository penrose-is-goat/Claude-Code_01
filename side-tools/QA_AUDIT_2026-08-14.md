# Side Tools QA Audit - 2026-08-14

## Scope

Nine independent read-only QA agents audited the three tools. Each tool received a prompt-fuzz agent, a non-prompt interaction agent, and a performance/cleanup agent. Application edits were consolidated centrally after comparing their findings.

At minimum, the audit exercised 100 randomized prompts and 100 non-prompt actions per tool. The performance agents also ran targeted API, database, timing, concurrency, and safety checks.

## Material Findings Fixed

- Macro Data Lab: corrected range parsing, coordinated series names, foreign-country routing, formulas, unsupported fundamentals, partial-verification labels, provider fallbacks, request cancellation, and stale-response protection.
- Fed Probability Tracker: corrected current/historical intent precedence, meeting selection, malformed and conflicting commands, history cache keys, stale-response protection, and resize/request races.
- Treasury Auction Tracker: corrected date-range/tenor collisions, metric and view inference, unsupported command rejection, record/PDF lookups, broad-query truncation, database indexes, sync backoff, request cancellation, and chart sampling across the full matched date range.
- Shared runtime: added compact and compressed JSON responses, bounded model-status checks, reusable caches, transport timeouts, and a short network-policy circuit breaker for repeated Windows socket-denial failures.

## Final Verification

- Fixed-seed parser replay: Macro 100/100, Fed 100/100, Treasury 100/100.
- Permanent automated suite: 118/118 tests passed.
- Python compilation: passed for all backend modules.
- Browser smoke tests: passed for all three tools.
- Macro reference request: two verified 57-observation earnings series, 2011-09-30 through 2025-09-30.
- Fed concurrency check: a slower historical request cannot overwrite a newer Current selection.
- Treasury broad query: 11,074 matches across 1979-10-31 through 2026-08-13, rendered as 584 date-spanning chart points with sampling disclosed.
- Treasury record lookup: 12 completed 10-year auctions in 2012, with 12 direct official result PDFs.
- Local model runtime: Ollama 0.32.13 with qwen3.5:9b installed and verified through live schema-constrained Macro, Fed, and Treasury routing checks.
- Model safety: model-assisted Macro rewrites cannot trigger open-ended provider search; Treasury model output cannot override identifiers, relative dates, security filters, reopening filters, or chart style.

## Macro Robustness Follow-up - 2026-08-16

Three additional agents independently audited difficult macro prompts, official PPI history, and provider coverage. Their combined checks exercised 46 adversarial prompts plus live BLS, FRED, Treasury, Yahoo, and World Bank series lookups.

- Core PPI requests now distinguish the modern combined final-demand measure, separate modern goods/services measures, and maximum honest official history. The tool never splices a synthetic pre-2010 services series without disclosure.
- Coordinated requests now retain shared context for claims, Fed target bounds, nominal/real comparisons, Treasury tenor lists, and CPI component lists.
- Partial or unresolved requests can no longer receive a `pass` verification label.
- Direct BLS failures now fall back to the mapped native FRED series ID instead of an application-only catalog key.
- Browser verification passed for the clarification workflow, full-window chart, hidden dashboard state, wrapped legend, tooltip crosshair, and per-series hover points.
- Final 46-prompt adversarial replay found zero wrong mappings and zero silent omissions; unsupported or ambiguous concepts now stop for an explicit clarification or carry a `partial` verification label.
